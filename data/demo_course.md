# 计算机网络课程资料（演示版）

本资料为《计算机网络》课程期末复习用资料，涵盖 OSI 模型、TCP/IP、TCP 三次握手、HTTP、DNS 与网络安全基础等核心考点，供 CoursePilot 演示使用。

## OSI 七层模型

OSI（开放式系统互联）模型将网络通信划分为七层，从上到下依次是：应用层、表示层、会话层、传输层、网络层、数据链路层、物理层。

- 应用层：为用户提供网络服务的接口，例如 HTTP、FTP、DNS 都工作在应用层。
- 表示层：负责数据格式转换、加密解密、压缩解压缩。
- 会话层：负责建立、管理和终止会话连接。
- 传输层：提供端到端的可靠或不可靠数据传输，典型协议是 TCP 和 UDP。
- 网络层：负责路由选择和逻辑地址寻址，典型协议是 IP、ICMP。
- 数据链路层：负责在物理链路上进行帧的传输和差错校验，典型协议是以太网。
- 物理层：负责比特流在物理介质上的传输，涉及电压、光信号等。

考试中常见考点：七层模型每一层的名称、顺序、典型协议，以及和 TCP/IP 四层模型的对应关系。

## TCP/IP 协议族

TCP/IP 是互联网的核心协议族，通常简化为四层：应用层、传输层、网络层、网络接口层。

TCP/IP 与 OSI 模型的对应关系：应用层对应 OSI 的应用层、表示层、会话层；传输层对应 OSI 传输层；网络层对应 OSI 网络层；网络接口层对应 OSI 数据链路层和物理层。

TCP（传输控制协议）是面向连接的、可靠的、基于字节流的传输层协议，提供流量控制和拥塞控制。UDP（用户数据报协议）是无连接的、不保证可靠性的传输层协议，开销小、速度快，常用于视频会议、DNS 查询等场景。

考试中常见考点：TCP 与 UDP 的区别、TCP 的可靠性机制（确认应答、超时重传、滑动窗口、拥塞控制）。

## TCP 三次握手

TCP 建立连接需要经过三次握手（Three-Way Handshake）：

1. 第一次握手：客户端向服务器发送一个 SYN 报文段，并将序号设置为一个随机初始值（seq=x），进入 SYN_SENT 状态。
2. 第二次握手：服务器收到 SYN 报文段后，回复一个 SYN+ACK 报文段，确认号设置为 x+1，同时自己也生成一个随机序号（seq=y），进入 SYN_RCVD 状态。
3. 第三次握手：客户端收到 SYN+ACK 后，向服务器发送一个 ACK 报文段，确认号设置为 y+1，双方进入 ESTABLISHED 状态，连接建立完成。

为什么需要三次握手而不是两次：主要是为了防止已失效的连接请求突然又传送到服务器，导致服务器错误地建立连接、浪费资源。三次握手可以让双方都确认彼此的发送和接收能力是正常的。

与三次握手对应的是四次挥手（连接释放），因为 TCP 是全双工通信，关闭连接时需要双方分别确认结束发送数据，所以需要四次交互。

考试中常见考点：三次握手的具体报文交互过程、每次握手报文中标志位与序号/确认号的变化、为什么是三次而不是两次或四次。这是本课程的高频考点。

## HTTP 协议

HTTP（超文本传输协议）是应用层协议，用于客户端（浏览器）与服务器之间传输网页等资源，默认基于 TCP 协议（端口 80），HTTPS 则在 TCP 之上加入 TLS/SSL 加密（端口 443）。

HTTP 常见方法：GET（获取资源）、POST（提交数据）、PUT（更新资源）、DELETE（删除资源）。

HTTP 状态码分类：
- 1xx：信息性状态码
- 2xx：成功状态码，例如 200 OK
- 3xx：重定向状态码，例如 301 永久重定向、302 临时重定向
- 4xx：客户端错误，例如 404 Not Found、403 Forbidden
- 5xx：服务器错误，例如 500 Internal Server Error

HTTP/1.1 引入了持久连接（Keep-Alive），HTTP/2 引入了多路复用，进一步提升了性能。

考试中常见考点：常见请求方法的语义、常见状态码的含义、HTTP 与 HTTPS 的区别、HTTP/1.1 与 HTTP/2 的主要改进点。

## DNS 域名解析

DNS（域名系统）负责将便于人类记忆的域名解析为 IP 地址，是一种分布式的层次化命名系统，默认使用 UDP 协议的 53 端口（大数据量查询时也可能使用 TCP）。

DNS 解析的大致流程：浏览器缓存 → 操作系统缓存 → 本地域名服务器 → 根域名服务器 → 顶级域名服务器（TLD） → 权威域名服务器，逐级查询直到获得目标域名对应的 IP 地址。

DNS 查询方式分为递归查询和迭代查询：递归查询由本地域名服务器代替客户端完成全部查询过程；迭代查询则是每一级服务器只返回下一步应该查询的服务器地址。

考试中常见考点：DNS 解析的完整流程、递归查询与迭代查询的区别、DNS 为什么默认使用 UDP。

## 网络安全基础

网络安全的三大基本目标是机密性（Confidentiality）、完整性（Integrity）、可用性（Availability），合称 CIA 三要素。

常见的网络攻击方式：
- DDoS（分布式拒绝服务攻击）：通过大量请求耗尽目标服务器资源，导致正常用户无法访问。
- 中间人攻击（MITM）：攻击者拦截并可能篡改双方通信内容。
- SQL 注入：通过在输入中拼接恶意 SQL 语句，非法获取或篡改数据库数据。
- 钓鱼攻击（Phishing）：伪造可信来源诱导用户泄露敏感信息。

常见防护手段：使用 HTTPS/TLS 加密通信、使用防火墙和入侵检测系统、对用户输入进行严格校验和参数化查询、及时更新系统补丁。

考试中常见考点：CIA 三要素的含义、常见攻击方式的原理与对应防护手段、对称加密与非对称加密的区别。
